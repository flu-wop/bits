# Changelog

All notable changes to the Breaks In The Simulation website will be documented in this file.

## [1.0.0] - 2026-02-08

### Added
- Complete website revamp with minimal, Cargo-inspired design
- Single-page layout with smooth scrolling navigation
- Comprehensive About Us section with mission, vision, and values
- Programming & Events section featuring all initiatives
- Creative Services section with detailed offerings
- Wellness Support section with resources and programs
- Show Your Support section with email signup and contact info
- Sticky header with auto-hide on scroll behavior
- Mobile-responsive design for all screen sizes
- SEO optimization with meta tags
- Form validation and handling
- Subtle entrance animations for content blocks
- Active navigation state highlighting
- Social media integration (Instagram, Spotify)
- Print-friendly styles
- Vercel deployment configuration
- Comprehensive documentation (README, DEPLOYMENT guide)

### Technical Details
- Pure HTML/CSS/JavaScript (no frameworks)
- Inter font for body text
- Playfair Display for headings
- Generous spacing with CSS custom properties
- Formspree integration ready for email forms
- Git-ready with .gitignore
- Compatible with macOS 11.7+

### Files Structure
```
breaks-in-the-simulation/
├── index.html           # Main website
├── css/styles.css       # All styles
├── js/main.js          # Interactions
├── images/logo.svg      # Logo
├── vercel.json         # Deployment config
├── README.md           # Documentation
├── DEPLOYMENT.md       # Deployment guide
├── CHANGELOG.md        # This file
└── .gitignore          # Git ignore rules
```
